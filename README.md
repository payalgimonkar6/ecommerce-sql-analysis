# E-Commerce Sales, Customer and Delivery Analysis Using SQL

## Project Overview

This project focuses on analyzing an E-Commerce dataset using SQL and MySQL.

The main objective is to understand customer behavior, sales performance, products, sellers, payments, reviews, and delivery performance by converting raw data into useful business insights.

## Project Objectives

- Analyze customer purchasing behavior
- Analyze order and sales performance
- Identify top-performing products and categories
- Analyze seller performance
- Understand payment methods and payment trends
- Analyze delivery performance
- Analyze customer review and satisfaction
- Apply advanced SQL concepts to solve business problems

## Dataset

The project uses the **Olist Brazilian E-Commerce Dataset**.

The dataset contains 9 related tables:

- Customers
- Orders
- Order Items
- Order Payments
- Order Reviews
- Products
- Sellers
- Geolocation
- Product Category Translation

## Key Analysis Performed

### Customer Analysis
- Total customers
- Unique customers
- Customers by state and city

- Top customers by number of orders
- Top customers by total spending

### Sales & Product Analysis
- Total revenue
- Revenue by product
- Top-selling products

### Seller Analysis
- Seller-wise revenue
- Top-performing sellers
- Seller ranking within each state
- Sellers with high order volumes

### Payment Analysis
- Total payment by payment type

- Payment trends

### Delivery Analysis
- Average delivery time
- Delivery performance by state
- Late delivery percentage

### Review Analysis
- Average review score

## Business Insights

The analysis helps identify:

- High-value customers
- Top-performing products and sellers
- Important revenue-generating categories
- Popular payment methods
- States with better or slower delivery performance
- Areas where customer satisfaction can be improved
